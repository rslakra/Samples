About VDI POC

Our Mission

The VDI POC project aims to demonstrate a robust, scalable, and secure virtual desktop infrastructure solution. We leverage modern containerization technologies, proxy capabilities, and advanced networking to deliver seamless remote desktop experiences.

Project Structure
